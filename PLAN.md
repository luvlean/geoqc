# PLAN.md — план оркестрации

Источник: `docs/plan_source.md` (исходный план курсовой). Контракты: `docs/CONTRACTS.md`. ТЗ агентов: `docs/tasks/`.

## Порядок действий

| Волна | Агенты | Зависимости | Выход |
|---|---|---|---|
| 0 | Координатор | — | скелет репозитория, venv, контракты, схема БД, ТЗ, git init |
| 1 (параллельно) | Orchestrator-infra, Data, Annotation, CV, Geo, Eval, App, Docs | контракты | модули с тестами на синтетике, реальные данные (Data), инфраструктура |
| 2 (интеграция) | CV → Geo → Annotation → Eval → App | реальные тайлы из волны 1 | детекции, расхождения, предразметка, метрики val, демо |
| 3 | QA/Review | всё выше | ревью, интеграционные тесты, отчёт `docs/qa/` |
| 4 | владельцы модулей | замечания QA | исправления (≤ 3 цикла) |
| 5 | Docs | финальный код | README, формулы, записка, презентация |
| Human | Студент | предразметка | правка разметки в QGIS, верификация ≥ 50 расхождений, прогон ноутбука обучения |
