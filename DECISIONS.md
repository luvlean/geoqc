# DECISIONS.md — журнал решений

Формат: `D-NNN` — дата — решение — обоснование — последствия.

## D-001 — 2026-09-26 — Выбор AOI делегирован Data Agent, критерии зафиксированы
Открытый снимок GSD ≤ 0.5 м с лицензией, допускающей обработку (OpenAerialMap CC-BY 4.0, Maxar Open Data CC BY-NC 4.0), AOI 5–10 км² со смешанной застройкой и хорошим покрытием OSM. Сначала проверяется покрытие OpenAerialMap по РФ; при отсутствии — зона за рубежом. Процедура выбора — скрипт `geoqc data search-aoi`, кандидаты — `reports/aoi_candidates.json`. Итоговый выбор дописывается сюда Data Agent как D-001a.

## D-002 — 2026-09-26 — Esri World Imagery только как подложка
Тайлы Esri/Bing/Яндекс — лицензированный контент, массовая выгрузка и обучение на них запрещены условиями использования и §7 плана. Разрешено: XYZ-подложка в Leaflet и QGIS с атрибуцией и API-ключом (`ARCGIS_API_KEY` в `.env`). Детекция и метрики — только по открытому снимку. Пайплайн принимает любой GeoTIFF на входе, компания может подставить свои лицензионные снимки.

## D-003 — 2026-09-26 — CI: GitHub Actions
Один workflow: ruff, pytest с сервисом PostGIS, сборка Docker-образа, проверка ноутбуков. GitLab CI не делается.

## D-004 — 2026-09-26 — Универсальный ноутбук дообучения
`notebooks/train_finetune.ipynb` автоопределяет CUDA / MPS / CPU; Colab-ячейки помечены и пропускаются локально; данные подаются архивом `make bundle`. Обучение запускает студент.

## D-005 — 2026-09-26 — Предразметка + правка в QGIS вместо разметки с нуля
Annotation Agent генерирует черновые контуры из вторичного источника (Microsoft/Google footprints) или бейзлайн-детекций; студент правит и подтверждает каждый объект (`verified=true`) в QGIS. Эталон остаётся независимым от OSM. Риск смещения к предразметке снижается слепой повторной разметкой 10 % тайлов (G2).

## D-006 — 2026-09-26 — Одно рабочее дерево вместо веток на агента
Агенты работают параллельно в одном каталоге; изоляция обеспечивается матрицей владения директорий (`docs/CONTRACTS.md §1`), коммит — один на задачу агента. В промышленной среде правило «одна задача — одна ветка» восстанавливается без изменений кода.

## D-007 — 2026-09-26 — Пакетная раскладка `src/geoqc/<module>` вместо `src/<module>`
Единый устанавливаемый пакет упрощает импорты, тесты и Docker. Имена модулей совпадают с планом: `data cv matching eval api` + `annotation`.

## D-008 — 2026-09-26 — Таблица `matches` отделена от `discrepancies`
Пары с IoU ≥ 0.5 нужны для G5 (средний IoU), но не являются расхождениями. В `discrepancies` — только три класса MVP.

## D-009 — 2026-09-26 — Конфиг по модулям `config/<module>.yaml`
Избегает конфликтов записи при параллельной работе; `geoqc.config.load_config()` собирает всё в один словарь.

## D-010 — 2026-09-26 — Порт PostGIS 5433
5432 занят локальным Postgres.app.

## D-011 — 2026-09-26 — Разбиение multipart-детекций в `matching run`
CV пишет MultiPolygon из одной части; многочастные появляются только после `make_valid`. `geoqc_split_multipart_detections` разбивает их до сопоставления, id таких строк меняются. Принято: сопоставление всегда идёт после записи детекций.

## D-012 — 2026-09-26 — Вспомогательные таблицы `det_suppressed` и `discrepancy_features`
Живут в `sql/002_matching.sql`. NMS не удаляет строки из `buildings_det`, а помечает их в `det_suppressed`. Eval и App исключают подавленные id при подсчёте детекций.

## D-013 — 2026-09-26 — `geometry_mismatch` не строго 1:1
Две детекции могут указывать на один объект OSM. Для очереди расхождений это допустимо: оператор видит обе.

## D-001a — 2026-09-26 — AOI: Пушкин, Отдельный парк, Тярлево
`geoqc data search-aoi` выбрал UAV-ортофото OpenAerialMap `6101142e5a90f10006fd3038` (Sergey Astakhov, CC-BY 4.0, 2021-07-26, GSD 0.073 м, UTM 36N). AOI 5.55 км², в bbox 2352 здания OSM. Смесь застройки покрывает все страты отбора тайлов, в отличие от кандидатов в Невском районе. Снимок пересэмплируется до 0.3 м. Кандидаты и причины — `reports/aoi_candidates.json`.

## D-014 — 2026-09-26 — Снимок OSM от 2026-07-24
Overpass-зеркало отдало данные на 2026-07-24 (кэш `data/raw/osm_2026-07-24.json`, ODbL). Дата фиксируется в `manifest.json` → `osm.snapshot_date`. Снимок сделан 2021-07-26, поэтому часть `missing_on_image` — здания, построенные после съёмки, а не ошибки карты. Это учитывается при разборе очереди и в тексте работы.

## D-015 — 2026-09-27 — SpaceNet 2 как внешний размеченный датасет
Из whitelist плана §9 взят SpaceNet 2 Buildings (train; Париж, Шанхай, Вегас по 100 тайлов, seed 42): публичный бакет без
регистрации, CC BY-SA 4.0, 0.3 м — как наши тайлы. INRIA требует регистрации. Назначение — smoke-обучение до готовности `val`,
опционально подмешивание к train и образец для своей разметки. Метрики на SpaceNet в работу не идут: G3 — только на `val`,
порог — только по holdout `val`. Разбор — `docs/datasets/spacenet2.md`.
