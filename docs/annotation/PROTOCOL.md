# Протокол разметки зданий

Протокол задаёт, что считается зданием в эталоне `data/labels/<split>/buildings.geojson`.
Эталон нужен для метрик детекции (G3–G5) и не заменяет OSM: OSM проверяется, а не служит истиной (D-005).
Пошаговая работа в QGIS описана в [INSTRUCTION_QGIS.md](INSTRUCTION_QGIS.md).

## 1. Что размечаем

Здание — капитальное сооружение с крышей, видимой на снимке целиком или почти целиком.

| Объект | Решение | Пояснение |
|---|---|---|
| Жилой дом, офис, цех, склад, гараж-бокс | **размечать** | основной класс |
| Ряд гаражей под общей крышей | **один полигон** | крыша сплошная |
| Части одного здания с крышами разной высоты (веранда, пристройка, корпус) | **один полигон** | контур по внешней границе всех частей (D-016) |
| Пристройка под той же крышей | **в составе основного** | |
| Разные здания с общей стеной (блокированные дома, отдельные корпуса) | **отдельные полигоны** | общая стена — общая граница |
| Навес без стен, автомойка-навес, АЗС | **не размечать** | нет замкнутого объёма |
| Киоск, павильон ≥ 12 м² | **размечать** | меньше 12 м² отбросит `finalize` |
| Строящееся здание с перекрытием | **размечать** | без перекрытия (котлован, каркас) не размечать |
| Руины без крыши | **не размечать** | |
| Теплица, парник | **не размечать** | |
| Здание частично под кроной | **размечать** | контур по видимым углам, скрытую часть достроить по прямым углам |
| Здание полностью под кроной | **не размечать** | его нельзя подтвердить по снимку |
| Трубы, резервуары, опоры | **не размечать** | |

Минимальная площадь — `min_area_m2` из `config/annotation.yaml` (12 м²). Меньшие полигоны `finalize` удаляет сам.

## 2. Контур по крыше

Контур рисуется **по крыше**, а не по фундаменту.

- На ортофото фундамент не виден, а крыша видна всегда. Разметка по крыше воспроизводима.
- Модель учится и предсказывает крыши. Предразметка Microsoft и Google тоже построена по крышам.
- У высоких зданий крыша смещена относительно фундамента из-за съёмки не строго в надир.
  Это смещение одинаково влияет на эталон и детекцию и не портит IoU между ними.
  На сравнение с OSM оно влияет, поэтому проверка геопривязки G1 берёт только здания до 3 этажей.

Карнизы и козырьки входят в контур, если они видны сверху как часть крыши.

## 3. Геометрия

- Одно здание — один полигон, даже если части крыши разной высоты. Отдельные полигоны — только для разных зданий.
  Если неясно, одно это здание или несколько, ставьте один полигон и пишите `спорно` в `notes`.
- Мультиполигон допустим только для одного здания с внутренним двором (дырка). Дворы-колодцы вырезаются.
- Полигоны соседних зданий **не перекрываются**. Общая стена — общая граница; в проекте включено «избегать пересечений».
- Точность — 1–2 пикселя (0.3–0.6 м). Прямые углы держать прямыми, лишние вершины не ставить.

## 4. Здания на границе тайла

- Размечается только часть здания **внутри рамки тайла** (жёлтая рамка `tiles_frame`).
- Можно нарисовать здание целиком: `finalize` обрежет его по тайлу.
- Если внутри тайла остаётся меньше 12 м², объект пропадёт при выгрузке. Это ожидаемо.

## 5. Поля объекта

| Поле | Значение |
|---|---|
| `tile_id` | заполняется автоматически по тайлу; `finalize` пересчитывает его сам |
| `split` | `val` или `test`, только чтение |
| `source` | `pre_annotation` для черновика, `manual` для нарисованного с нуля |
| `verified` | `true`, когда объект проверен глазами и соответствует протоколу |
| `annotator` | фамилия разметчика |
| `notes` | необязательный комментарий: `под кроной`, `стройка`, `спорно` |

Объект с `verified=false` в итоговом файле — ошибка валидации `not_verified`.

## 6. Повторная разметка для G2

- Тайлы из `data/labels/recheck_tiles.csv` (около 10 %, голубая рамка) размечаются второй раз **вслепую** в слой `recheck`.
- При повторной разметке слои `buildings`, `osm_buildings` и `secondary_buildings` выключены. Черновик не используется.
- Лучше делать повтор на следующий день, чтобы не рисовать по памяти.
- G2 — средний IoU пар «основная разметка — повторная» на этих тайлах. Порог — 0.80 (`config/quality_gates.yaml`).
  Формула — в [../metrics_and_formulas.md](../metrics_and_formulas.md).

## 7. Спорные случаи

Если решение не очевидно, ставьте `verified=true` и пишите причину в `notes`.
Спорные объекты не удаляются молча: по `notes` их можно найти и пересмотреть.
