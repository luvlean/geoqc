## Правила текста

- Числа результатов — только плейсхолдеры `{{metrics.<путь>}}` (ключи `reports/metrics.json`, схема — CONTRACTS §3.9) или `{{manifest.<путь>}}` (`data/manifest.json`); подстановка — `scripts/render_metrics_table.py fill` (предложение в `docs/DOCUMENTATION_PLAN.md` §5). Число без источника в тексте не допускается.
- Пороги гейтов — из `config/quality_gates.yaml`, цитируются как целевые значения, а не результаты.
- Формулы — LaTeX, обозначения по `docs/metrics_and_formulas.md` §0; в записке формулы не переопределяются, а ссылаются на одну нотацию.
- Ссылки на источники — только реальные (официальные репозитории, страницы проектов, статьи с проверяемыми идентификаторами); DOI/arXiv указываются только при уверенности, иначе — название, авторы, год, URL.
- Рисунки — из `reports/figures/`, схемы — mermaid из `docs/`; каждая подпись содержит путь к файлу-источнику.
- Непройденные гейты описываются честно: фактическое значение, причина, применённый fallback (план §6, §8).

## Сборка

Исходники глав хранят плейсхолдеры. Заполненная копия: `python scripts/render_metrics_table.py fill docs/thesis/*.md --out-dir build/thesis` (ненулевой код при отсутствующих ключах). Далее — конвертация в DOCX/PDF средствами студента (pandoc или редактор); шаблон оформления — по требованиям кафедры.
